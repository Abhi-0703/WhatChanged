# Sample Frames Directory

This folder contains pre-rendered, people-free sample image frames used for offline demonstrations, unit tests, and replay mode:

1. `01_empty_desk.jpg` — Empty workstation desk reference frame.
2. `02_bottle_added.jpg` — A water bottle placed on the right side of the desk.
3. `03_bottle_moved.jpg` — The water bottle moved across to the left side of the desk.
4. `04_notebook_added.jpg` — A notebook placed on the desk beside the bottle.
5. `05_bottle_removed.jpg` — The bottle removed, leaving only the notebook.
