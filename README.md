# What Changed? (Continuous Visual Change Watcher)

> A camera-watching tool that stays silent until something changes, then uses Gemma 4 to explain what changed, logs it on a timeline, and fires alerts for user-written rules.

**Hackathon Project:** C³ × Hacktoberfest Hack Day (Hack Day Pune × Cloud Computing Club)  
**Challenge:** Best Open-Source AI Project + Best Use of Gemma 4  
**Core Model:** Open-weight Gemma 4 running locally via Ollama (offline-first) with optional Gemini API cloud fallback.

*Full documentation, architecture diagrams, and quickstart will be provided in Phase 8.*
